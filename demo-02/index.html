프로젝트 사례 예제

책등 사진에서 청구기호 읽기

입력부터 결과 확인까지, OCR 프로토타입의 범위를 독자가 따라갈 수 있게 설명합니다.

예제 처리 흐름

  1. 책등 사진 입력
  2. 라벨 영역 선택
  3. 문자 인식
  4. 기록과 확인

문제 정의

책등 사진에는 여러 권의 책이 한꺼번에 찍힙니다. 전체 사진을 읽으면 책 제목과 청구기호가 뒤섞일 수 있습니다.

구현 범위

책마다 라벨 영역을 선택하고, 영역별 OCR 결과를 책의 순서와 함께 기록하는 데모를 가정했습니다.

검증 계획

사람이 기록한 청구기호와 OCR 결과를 비교해 한 글자도 틀리지 않은 비율과 문자 오류율을 살펴봅니다.
