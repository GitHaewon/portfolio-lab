# Portfolio Lab

[연구 포트폴리오](https://githaewon.github.io/portfolio-lab/)와 기존 연습용 데모를 제공하는 GitHub Pages 저장소입니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 연구 포트폴리오 메인 |
| `projects/` | 프로젝트 상세 페이지 |
| `certificates.html` | 인증서 페이지 |
| `lab.html` | 연습용 데모 목록 |
| `demo-01/index.html` | 한 페이지 연구 포트폴리오 예제 |
| `demo-02/index.html` | 프로젝트 사례 소개 예제 |
| `assets/lab-style.css` | 연습용 데모 공통 스타일 |

브라우저에서 `index.html` 또는 `lab.html`을 열어 로컬에서 확인할 수 있습니다. `main`에 커밋하면 GitHub Pages에 반영됩니다.
