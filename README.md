# Portfolio Lab

GitHub Pages로 포트폴리오와 프로젝트 소개 페이지를 연습하는 저장소입니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 데모 목록 |
| `demo-01/index.html` | 한 페이지 연구 포트폴리오 예제 |
| `demo-02/index.html` | 프로젝트 사례 소개 예제 |
| `assets/style.css` | 데모 공통 스타일 |

GitHub에서 원하는 HTML 파일을 열고 내용을 수정한 뒤 `main`에 커밋하면 GitHub Pages에 반영됩니다. 새 데모는 `demo-03/index.html`처럼 폴더를 하나 만들고 루트 `index.html`의 데모 목록에 링크를 추가하면 됩니다.

브라우저에서 `index.html`을 열어 로컬에서도 확인할 수 있습니다. 데모에서 공통 CSS를 가져올 때는 `../assets/style.css`를 사용합니다.
